# 夢疑 MOE

2D 像素風刷寶遊戲，用瀏覽器就能玩。

## 直接玩

打開這個網址（建議用電腦的 Chrome 或 Edge）：

**https://charlie1033.github.io/moe/**

存檔存在那台電腦的瀏覽器裡。要把角色帶到別台電腦：遊戲裡按 H（說明）→ 匯出存檔，到另一台再匯入。

## 下載到電腦玩

按右上角綠色的 **Code** → **Download ZIP**，解壓縮後雙擊 `index.html`。

## 素材

角色、怪物、地板等像素圖來自 0x72 DungeonTileset II、Dungeon Crawl Stone Soup、Animated Wild Animals（皆為 CC0 公眾領域）。其餘圖片為 AI 生成。

## 給接手開發的人

先讀 `開發規則.md`。終局玩法的設計在 `終局設計_v2.12.md`。
